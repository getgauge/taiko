---
title: "closeIncognitoWindow()"
description: "Closes the specified browser window."
---

Closes the specified browser window.

## Examples

```js
await closeIncognitoWindow('windowName') - Close incognito window
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `arg` | `unknown` |  |
| `windowName` | [string](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/String) | incognito window name |

## Returns

This API does not return any values.
