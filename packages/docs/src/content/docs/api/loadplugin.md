This function is used by taiko to initiate the plugin.

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `id` | `unknown` |  |
| `init` | [Function](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Function) | callback method to set taiko instance for plugin |
| `ID` | [string](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/String) | unique id or name of the plugin |

## Returns

This API does not return any values.
