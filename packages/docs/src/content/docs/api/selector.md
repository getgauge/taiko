title: "selector()"
description: "Identifies an element on the page."
---

Identifies an element on the page.

## Examples

```js
link('Sign in')
```

```js
button('Get Started')
```

```js
$('#id')
```

```js
text('Home')
```

## Parameters

| Name | Type | Description |
| --- | --- | --- |
| `text` | [string](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/String) | Text to identify the element. |

## Returns

This API does not return any values.
