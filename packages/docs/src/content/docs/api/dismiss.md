Dismiss action to perform on dialogs

## Examples

```js
prompt('Message', async () => await dismiss())
```

## Parameters

This API does not have any parameters.

## Returns

| Type | Description |
| --- | --- |
| [Promise](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Promise)<`void`> | Resolves when dialog is dismissed |
